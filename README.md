# Gotham — Landing Page de Wallpapers 4K

Landing page temática inspirada na estética sombria de Gotham, desenvolvida com **HTML5, CSS3 e JavaScript puro**. O projeto apresenta uma coleção fictícia de wallpapers 4K com visual cinematográfico, animações suaves, suporte a múltiplos idiomas e elementos de conversão para produto digital.

---

## ✨ Funcionalidades

- 🎨 Interface responsiva (desktop e mobile)
- 🌃 Hero section com skyline animado
- 🦇 Identidade visual inspirada em Gotham
- 🔁 Carrossel contínuo de artes
- ❓ FAQ em acordeão
- 🌍 Internacionalização (**PT-BR** e **ES**)
- 💾 Salvamento do idioma no `localStorage`
- 🛒 Popups dinâmicos simulando compras em tempo real
- 🔗 CTAs atualizados automaticamente conforme o idioma
- ⚡ Projeto leve, sem frameworks

---

## 🛠️ Tecnologias utilizadas

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- Google Fonts (**Oswald**, **Inter** e **JetBrains Mono**)

---

## 🌍 Internacionalização

O sistema de idiomas é carregado dinamicamente a partir da pasta `lang/` utilizando `fetch()`.

### Recursos

- Tradução via atributo `data-i18n`
- Atualização automática do atributo `lang` do HTML
- Detecção do idioma do navegador
- Persistência da escolha do usuário

---

## 🛒 Popup de compra

Os dados exibidos no popup são carregados do arquivo `compradores.json`, contendo nomes e cidades fictícias para simular atividade recente de compra.

---

## 🎨 Design

A identidade visual utiliza:

- Fundo escuro com granulação
- Tipografia condensada para títulos
- Paleta **preto + amarelo + cinza**
- Sombras suaves e alto contraste
- Composição inspirada em quadrinhos noir e cinema urbano
